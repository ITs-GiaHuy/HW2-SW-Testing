## Bug Description
The Order History (Profile) page does not contain any `<h1>` headings. It uses `<h2>` for top-level section titles ("Hồ sơ của bạn", "Lịch sử đơn hàng"), which violates semantic HTML guidelines and accessibility standards.

## Steps to Reproduce
1. Login to the application
2. Navigate to `/profile`
3. Inspect the page headings.

## Expected Result
The page should contain exactly one `<h1>` heading (e.g., "Hồ sơ của bạn" or a main page title).

## Actual Result
The page uses `<h2>` for titles and is completely missing an `<h1>`.

## Environment
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC18 from FR-11
- Assertion Error: `Error: expect(locator).toHaveCount(expected) failed ... Expected: 1, Received: 0`

## Severity
Low — Does not affect core functionality, but impacts SEO and screen reader accessibility.
