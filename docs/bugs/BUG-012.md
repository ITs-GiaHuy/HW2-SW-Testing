## Bug Description
The Frontend CSV parser (`App.jsx`) uses a naive `.split(',')` method to parse CSV rows. It does not support standard RFC 4180 parsing for fields enclosed in double-quotes that contain commas (e.g., `"Mô tả, chi tiết"`).

## Steps to Reproduce
1. Log in as admin and go to Import Products.
2. Upload a CSV file with the row: `SP Test,50000,"Mô tả dài, chi tiết",http://img.com/1.jpg,1`
3. Check the payload sent to the backend.

## Expected Result
The parser should recognize `"Mô tả dài, chi tiết"` as a single field.

## Actual Result
The parser splits on the comma inside the quotes, shifting all subsequent columns (imageUrl becomes `chi tiết"`, category_id becomes `http://img.com/1.jpg`), corrupting the data.

## Environment
- SUT: Frontend Admin (`App.jsx`)
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC26, TC27, TC28 from FR-16
- Playwright Error: `Timeout 30000ms exceeded` due to unexpected parsing failures leading to missing fields or backend validation errors.

## Severity
Medium — Corrupts data for users utilizing valid CSV structures with commas.
