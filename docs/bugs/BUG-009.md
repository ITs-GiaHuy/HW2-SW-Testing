## Bug Description
The "Đã xác nhận" (Confirmed) order status badge uses `bg-indigo-100`, which mismatches the expected color palette in the design specifications.

## Steps to Reproduce
1. Log in with an account having a confirmed order
2. Navigate to `/profile`
3. Inspect the CSS classes for the "Đã xác nhận" status badge

## Expected Result
The badge color should match the standard design system (e.g., green/blue pattern).

## Actual Result
The badge uses `bg-indigo-100 text-indigo-800`.

## Environment
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC07 from FR-11
- Assertion Error: `toHaveCSS()` failed for background color.

## Severity
Low — Cosmetic discrepancy.
