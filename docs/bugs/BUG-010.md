## Bug Description
The `/api/admin/import-products` endpoint verifies JWT tokens but entirely omits checking if the `user.role` is `admin`. Any authenticated user can POST to this endpoint and inject products into the database.

## Steps to Reproduce
1. Log in as a standard user (`test@eshop.com`) and retrieve the JWT.
2. Send a POST request to `/api/admin/import-products` with a valid payload, attaching the user JWT.

## Expected Result
API returns `403 Forbidden` (Unauthorized action).

## Actual Result
API returns `200 OK` and executes the import successfully.

## Environment
- SUT: Backend Express API
- OS: Linux

## Test Evidence
- Test Case: TC03 from FR-16
- Assertion Error: Expected HTTP 403, Received HTTP 200.

## Severity
Critical — Massive security vulnerability allowing arbitrary product injection.
