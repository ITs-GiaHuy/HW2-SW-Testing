## Bug Description
The Order Status badge for "Confirmed" (Đã xác nhận) uses an incorrect CSS background color (`bg-indigo-100`), which fails the UI test expectations for the color scheme.

## Steps to Reproduce
1. Login to the application
2. Navigate to `/profile`
3. View an order with the "confirmed" status ("Đã xác nhận")
4. Inspect the CSS background color of the status badge.

## Expected Result
The background color should match the standard design system (e.g., green or blue based on requirements).

## Actual Result
The badge uses `bg-indigo-100` (`rgba(224, 231, 255, 1)`).

## Environment
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC07 from FR-11
- Assertion Error: `Error: expect(locator).toHaveCSS(expected) failed`

## Severity
Low — Cosmetic issue, does not affect functionality.
