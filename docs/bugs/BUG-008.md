## Bug Description
When a user has no orders, the Profile page displays a simple text paragraph: "Bạn chưa có đơn hàng nào." but fails to include an illustrative icon as required by the Empty State design specifications (FR-24).

## Steps to Reproduce
1. Log in with an account that has 0 orders (e.g., admin@eshop.com)
2. Navigate to `/profile`
3. Observe the "Lịch sử đơn hàng" section

## Expected Result
An empty state message with an accompanying visual icon/illustration should be visible.

## Actual Result
Only text `<p>` is rendered, no icon is present.

## Environment
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC11 from FR-11
- Playwright Error: `Timeout 30000ms exceeded` waiting for `emptyStateIcon` to be visible.

## Severity
Low — Cosmetic issue missing UI requirements.
