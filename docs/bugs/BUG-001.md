## Bug Description
The Login page displays a hardcoded, generic error message ("Đăng nhập thất bại. Vui lòng kiểm tra lại.") for all failed login attempts, rather than displaying the specific error reason provided by the backend API.

## Steps to Reproduce
1. Navigate to `/login`
2. Enter valid email but incorrect password, OR enter email of a locked account.
3. Click "Sign In"

## Expected Result
UI should display specific error from backend (e.g., "Tài khoản bị khóa", "Sai mật khẩu").

## Actual Result
UI always displays generic error: "Đăng nhập thất bại. Vui lòng kiểm tra lại."

## Environment
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC06, TC12, TC14, TC15, TC16, TC20, TC21 from FR-02
- Assertion Error: `Error: expect(locator).toHaveText(expected) failed`

## Severity
Medium — Users cannot distinguish between wrong passwords or locked accounts, leading to poor UX.
