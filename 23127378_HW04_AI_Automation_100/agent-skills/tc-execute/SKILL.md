# tc-execute — Test Suite Runner & Result Collector

> **Purpose:** Execute the complete test suite across all browser projects,
> collect results (JSON, screenshots, traces), generate the HTML report,
> and produce a structured execution summary for the reporting phase.

## When to Use

Invoke this skill **after** `tc-configure` has set up the Playwright configuration.
This is the fourth step in the workflow.

**Trigger phrases:** `/tc-execute`, `run tests`, `execute test suite`,
`run playwright`, `run all tests`, `execute suite`.

---

## Prerequisites

- `tc-configure` has been executed — `playwright.config.ts` exists
- `tc-codegen` has been executed — test spec files exist
- SUT (System Under Test) is running:
  - Backend: `http://localhost:3000` (verify with `curl http://localhost:3000/api/products`)
  - Frontend Web: `http://localhost:5173`
  - Frontend Admin: `http://localhost:5174`
- Browsers are installed: `npx playwright install`

| Source | Description |

## Processing Steps

### Step 1 — Health Check

Before running tests, verify all SUT services are accessible:

```bash
# Check backend API
curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/api/products
# Expected: 200

# Check web frontend
curl -s -o /dev/null -w "%{http_code}" http://localhost:5173
# Expected: 200

# Check admin frontend
curl -s -o /dev/null -w "%{http_code}" http://localhost:5174
# Expected: 200
```

If any service returns non-200, **STOP** and inform the user:

```
⚠️ SUT Health Check Failed
- Backend (port 3000): {status}
- Web Frontend (port 5173): {status}
- Admin Frontend (port 5174): {status}

Please start the SUT services before running tests.
Backend: cd backend && npm start
Frontend Web: cd frontend-web && npm run dev
Frontend Admin: cd frontend-admin && npm run dev
```

### Step 2 — Run Full Test Suite

Execute all tests across all browser projects:

```bash
cd e2e
npx playwright test --reporter=html,json,list 2>&1 | tee test-output.log
```

This runs:
- `web-chromium` — Web tests on Chromium
- `web-firefox` — Web tests on Firefox
- `web-webkit` — Web tests on WebKit
- `admin-chromium` — Admin tests on Chromium
- `admin-firefox` — Admin tests on Firefox
- `admin-webkit` — Admin tests on WebKit

### Step 3 — Collect Results

After test execution completes:

1. **JSON Results:** Read `e2e/results.json` (generated by JSON reporter)
2. **Screenshots:** Collect from `e2e/test-results/` directory
3. **HTML Report:** Available at `e2e/playwright-report/`
4. **Traces:** Available for retried tests in `e2e/test-results/`

### Step 4 — Parse & Analyze Results

Parse `results.json` and compute:

- Total tests executed
- Tests passed / failed / skipped per project (browser)
- Tests passed / failed / skipped per feature
- Failed test details: test name, error message, screenshot path
- Execution time per project

---

## Error Handling

- **SUT not running:** Stop and provide startup commands
- **Browser not installed:** Run `npx playwright install` automatically
- **All tests fail:** Likely a configuration issue — check baseURL and .env
- **Timeout errors:** May indicate SUT performance issues — suggest increasing timeout

---

## Constraints

- **Must run ALL projects** — do not skip any browser
- **Must produce JSON results** — needed for tc-report
- **Must produce HTML report** — with StudentID in metadata
- **Must collect screenshots** — needed for bug evidence
- **Do not modify test files** — only run what tc-codegen produced
