## Bug Description
The Login page heading incorrectly displays "Đăng Ký" (Register) instead of "Đăng Nhập" (Login).

## Steps to Reproduce
1. Navigate to `/login`
2. Observe the page heading at the top of the form.

## Expected Result
Page heading displays "Đăng Nhập"

## Actual Result
Page heading displays "Đăng Ký"

## Environment
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC28 from FR-02
- Assertion Error: `Error: expect(locator).toHaveText(expected) failed`

## Severity
Low — Cosmetic issue, but confusing for users.
