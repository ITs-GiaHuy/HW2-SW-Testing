## Bug Description
The Order History (Profile) page lacks a top-level `<h1>` heading. The main titles "Hồ sơ của bạn" and "Lịch sử đơn hàng" use `<h2>` tags instead. This violates semantic HTML rules and accessibility requirements (FR-21).

## Steps to Reproduce
1. Log in with a valid account
2. Navigate to `/profile`
3. Inspect the DOM elements for the main page titles

## Expected Result
There should be exactly one `<h1>` tag acting as the main heading of the page.

## Actual Result
Only `<h2>` tags are present.

## Environment
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC18 from FR-11
- Assertion Error: `toHaveCount(1)` failed (received 0).

## Severity
Low — Does not break functionality but affects accessibility and SEO.
