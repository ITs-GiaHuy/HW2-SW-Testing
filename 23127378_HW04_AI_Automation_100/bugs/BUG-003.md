## Bug Description
The Email and Password input fields on the Login page are using `type="text"`. This exposes the user's password in plain text and prevents browsers from offering proper email autocomplete.

## Steps to Reproduce
1. Navigate to `/login`
2. Inspect the Email and Password input fields in the DOM.

## Expected Result
Email input should be `type="email"`, Password input should be `type="password"`.

## Actual Result
Both inputs are `type="text"`.

## Environment
- Browser: Chromium, Firefox, WebKit
- OS: Linux

## Test Evidence
- Test Case: TC24, TC25 from FR-02
- Assertion Error: `Error: expect(locator).toHaveAttribute(expected) failed`

## Severity
High — Exposing passwords in plain text is a significant security/privacy risk for users in public spaces.
